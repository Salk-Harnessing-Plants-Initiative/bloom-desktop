## 1. Deterministic regression tests for the stdout interleaving race (TDD red)

- [x] 1.1 Add `pytest-timeout` to the Python dev dependencies (`pyproject.toml`) and run `uv lock` to regenerate `uv.lock` in the same commit — CI's `lint-python`/`test-python`/`build-python` jobs run `uv sync --frozen`, which fails hard if the lockfile is out of sync with `pyproject.toml`. Apply `@pytest.mark.timeout(30)` (or similar) to every test added in this section — a future lock-ordering bug should fail fast and loudly, not hang the whole `pytest` run silently, which is exactly the failure mode this change exists to eliminate.
- [x] 1.2 In `python/tests/test_protocol_io.py` (new file — this is the definitive name, not `test_ipc_handler_stdout_race.py`), add a fake stdout helper (e.g. `_InterleavingStdout`) whose `write()` splits any payload over a size threshold into two writes, using two `threading.Event`s (`gap_open`, `resume`) rather than `time.sleep()`: after writing the first chunk it sets `gap_open` then blocks on `resume` (bounded wait, e.g. 2s) before writing the remainder. The test **must not** use pytest's `capsys` fixture for this (it also substitutes `sys.stdout` and will conflict) — use `monkeypatch.setattr(sys, "stdout", fake)` directly.
- [x] 1.3 Write `test_concurrent_frame_and_data_do_not_interleave`: the test's main thread orchestrates the handshake — start thread A calling `protocol_io.write_line(large_fake_frame_payload)`, wait on `gap_open` (bounded — **assert the wait returned `True`**, not just that it didn't raise, so a miscalibrated size threshold that never triggers a split can't silently degrade this into a no-op test that still passes), dispatch thread B calling `protocol_io.write_line(small_data_payload)`, and set `resume` **immediately after dispatching B** (not after B completes — once the fix's lock exists, B blocks on it for A's whole write, so waiting for B to finish before releasing `resume` would hang the test itself). Join both threads with timeouts. Assert the fake's recorded output reconstructs into exactly two complete, correctly-formed lines, in either order.
- [x] 1.4 Write `test_concurrent_frame_and_error_do_not_interleave`: same structure as 1.3, pairing a large payload against a small `ERROR:`-shaped payload (covers the spec's "or `send_error()`" alternative, not just `send_data()`).
